# DLFromScratch 🧠

*Implementing Machine Learning and Deep Learning algorithms from scratch based on foundational books and self-study.*

## 📖 About This Project
This repository serves as a personal portfolio and learning tracker. Instead of relying solely on high-level APIs (like PyTorch's pre-built layers or scikit-learn), the goal of this project is to build core ML and DL algorithms from scratch. 

This "from scratch" approach ensures a deep mathematical and practical understanding of fundamental mechanisms, including forward passes, backpropagation, optimizers, and loss functions.

## 🚀 Progress & Topics Covered
*Here is a living list of what has been implemented so far:*

*   **Linear Regression:** Implemented completely from scratch (includes custom data modules, synthetic data generation, and a custom Stochastic Gradient Descent optimizer).
*   *(More algorithms and models will be added as the learning journey continues...)*

## 🛠️ Technologies Used
*   **Python 3**
*   **PyTorch** (utilized primarily for basic tensor operations and its autograd engine, rather than its pre-built neural network modules)
